## Возможности

- Сканирование выбранных расположений до удаления файлов
- Круговая диаграмма с адаптивными капсулами категорий, обновляющаяся после очистки
- Очистка временных файлов Windows
- Очистка кэша Adobe, Discord, Telegram, Teams, Spotify, браузеров и игровых лаунчеров
- Отдельный режим разработчика для кэшей pip, npm, pnpm, Yarn, Gradle и NuGet
- Анализ и очистка корзины Windows с отдельным подтверждением
- Поддержка Chrome, Firefox, Edge, Brave и Яндекс Браузера
- Официальные фирменные иконки, встроенные в приложение
- Создание сжатого ZIP-бэкапа и проверка его целостности перед очисткой
- Восстановление бэкапа и быстрое удаление сразу нескольких старых копий
- Необязательное автоудаление бэкапов старше 7, 30 или 90 дней
- Напоминание о бэкапах, которые продолжают занимать место
- Точное отображение очищенного и оставшегося объёма
- Отчёт о файлах, заблокированных Windows или запущенными программами
- Графитовый интерфейс в стиле liquid glass с тёплым жёлтым акцентом, боковой навигацией и крупными иконками
- Быстрые режимы для обычной, игровой очистки и сценария разработчика
- Адаптивная компоновка со сворачиваемым меню и прокруткой в небольшом окне

## Быстрый запуск

1. [Скачайте `cache_clear.exe`](https://github.com/sweetenerbae/cache-cleaner/raw/refs/heads/main/dist/cache_clear.exe).
2. Запустите скачанный файл.
3. Подтвердите запрос Windows на права администратора.
4. Выберите категории и нажмите **Сканировать** или **Начать очистку**.

Для готового EXE устанавливать Python не нужно. Windows SmartScreen может показать предупреждение, потому что файл пока не подписан цифровым сертификатом.

> Перед очисткой закройте браузеры и выбранные приложения. Файлы, которые сейчас использует Windows или другая программа, будут безопасно пропущены.

## Что очищается

| Категория | Расположение |
|---|---|
| Windows | Пользовательские временные файлы, `Windows\Temp`, Prefetch |
| Adobe | Media Cache, Media Cache Files и выбранная папка кэша |
| Discord | Cache, Code Cache, GPUCache |
| Приложения | Медиакэш Telegram, кэш Microsoft Teams, интерфейсный и медиакэш Spotify |
| Браузеры | Кэш Chrome, Firefox, Edge, Brave и Яндекс Браузера |
| Игровые лаунчеры | Веб-кэш интерфейса Steam, Epic Games Launcher и кэш Battle.net |
| Режим разработчика | Кэши зависимостей pip, npm, pnpm, Yarn, Gradle и NuGet |
| Корзина | Содержимое корзины Windows; выключено по умолчанию и не попадает в бэкап |

Приложение не выбирает установленные игры, исходный код, `node_modules`, виртуальные окружения и папки сборки проектов. После очистки кэшей разработчика зависимости при необходимости загрузятся заново.

Корзина и игровые лаунчеры выключены по умолчанию. Инструменты разработчика неактивны, пока не включён **Режим разработчика**. Содержимое корзины невозможно включить в ZIP-бэкап, поэтому оно удаляется только после отдельного подтверждения.

## Бэкапы и приватность

Если включена защита, перед очисткой Cache Cleaner создаёт сжатый ZIP-архив и проверяет, что его содержимое действительно упаковано. Бэкапы хранятся только на компьютере пользователя:

```text
%LOCALAPPDATA%\CacheCleaner\backups
```

Логи работы и файлы бэкапов исключены из Git и при обычных коммитах не загружаются в репозиторий.

В центре восстановления показываются исходный и сжатый размеры. Один бэкап можно восстановить, несколько старых копий — выбрать и быстро удалить, а копии старше 7, 30 или 90 дней — удалять автоматически. Автоудаление по умолчанию выключено. После очистки приложение напоминает, что новый бэкап продолжает занимать место на диске.

Cache Cleaner не собирает телеметрию и не отправляет пути, логи или бэкапы в интернет. Сканирование, очистка и восстановление выполняются локально.

## Запуск из исходного кода

```bat
git clone https://github.com/sweetenerbae/cache-cleaner.git
cd cache-cleaner
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Сборка EXE

Запустите безопасный скрипт сборки:

```bat
build_exe.bat
```

Он собирает приложение отдельно, ждёт закрытия запущенного Cache Cleaner и помещает результат в `dist\cache_clear.exe`.

```text
backup_system.py     Создание и восстановление бэкапов
restore_window.py    Интерфейс управления бэкапами
utils.py             Пути Windows и общие модели данных
assets/brand-icons   Встроенные иконки приложений и браузеров
```
